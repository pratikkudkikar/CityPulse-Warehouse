# CityPulse Web Demo

Live demo UI for CityPulse with:
- Gradient hero section
- State-level satellite map with exact coordinates

## Run live demo (development)

```bash
cd /home/runner/work/CityPulse-Warehouse/CityPulse-Warehouse/web
npm install --include=dev
npm run demo:dev
```

Open in browser:
- http://localhost:4173/live-demo

## Run live demo (production preview)

```bash
cd /home/runner/work/CityPulse-Warehouse/CityPulse-Warehouse/web
npm install --include=dev
npm run demo:preview
```

Open in browser:
- http://localhost:4173/live-demo

If you're in a remote container/VM, open the forwarded URL for port `4173`.
